## Teknologi

TypeScript · HTML · dijalankan di browser

Kode ditulis dalam TypeScript (`.ts`), dikompilasi ke JavaScript (`.js`) dengan `npx tsc`, lalu dijalankan lewat file HTML di browser. Input diambil dengan `prompt()` dan hasilnya ditampilkan ke halaman dengan `output.innerHTML`.
